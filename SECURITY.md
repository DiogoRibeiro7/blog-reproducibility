# Reporting a vulnerability

For a security issue, use the repository's **Security → Report a vulnerability**
option when available. Otherwise, use a private contact method listed on the
[maintainer's GitHub profile](https://github.com/DiogoRibeiro7). Avoid posting
credentials, private data, or exploitable details in a public issue.

Include the affected commit or version, a minimal reproduction, the potential
impact, and any suggested fix. Security fixes are developed on `main`; older
reproducibility snapshots are not maintained as separate release branches.

Numerical disagreements, incorrect article values, and rendering defects belong
in the public issue tracker so the evidence and resolution remain inspectable.
